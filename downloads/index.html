Free Downloads

Free MT5 technical indicators, built by QDB. They live in the #free-tools channel of the QDB Discord, so join the server and grab them from there. Joining is free.

Join the QDB Discord

How to get them

  1. Join the QDB Discord (free).
  2. Open the #free-tools channel.
  3. Download the indicator files and add them to MT5 (File → Open Data Folder → MQL5 → Indicators, then restart MT5 or refresh the Navigator).
